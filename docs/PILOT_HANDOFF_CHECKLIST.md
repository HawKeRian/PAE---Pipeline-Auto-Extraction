# Pilot Handoff Checklist

- [ ] Product Owner names one data analyst and one data engineer participant.
- [ ] Participants receive synthetic CSV, JSON Lines, and disposable PostgreSQL use cases.
- [ ] Facilitator sends `USER_GUIDE.md`, `PILOT_TRAINING.md`, and support/incident contact details.
- [ ] Pilot environment passes `/health`, `/ready`, smoke test, backup, and alert receiver test.
- [ ] No production credential, regulated data, or real customer row is present.
- [ ] Each participant completes the scored journey without developer actions.
- [ ] Feedback forms are normalized into `PILOT_RESULTS.md` without personal/sensitive data.
- [ ] Critical/High findings have zero unresolved items before the final Go/No-Go review.
- [ ] Product Owner records Go/No-Go decision, release ID, operator, deployment time, and monitoring
      window.
