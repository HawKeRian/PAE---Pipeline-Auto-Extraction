# PAE 0.1.0 MVP Release Candidate Notes

Date: 2026-09-27

This candidate delivers secure file/database analysis, masked profiling, user-confirmed schemas,
Thai/English Local Llama rule proposals, versioned specifications, sandbox preview, Python/SQL/
JavaScript generation, reusable folder scan-on-run packages, authenticated ZIP exports, production
UI, job recovery, stale revision handling, deletion, security controls, readiness, metrics, backup,
and Podman deployment assets.

Known boundaries: one source per MVP pipeline; advanced Join and orchestrator-specific exports are
Deferred; SQL packages require disposable target validation; TLS and at-rest encryption are host/
reverse-proxy responsibilities; multiple replicas require a shared rate limiter/queue; a real pilot
and production observation period remain required before public MVP release.
